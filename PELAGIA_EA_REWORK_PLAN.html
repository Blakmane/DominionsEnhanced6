EA Pelagia (Pearl Kings) — Rework Implementation Plan

Target: #selectnation 40 — EA Pelagia, in DomEnhanced2_GitHub.dm. Branch pelagia-rework. Source: brain-dump from the Pelagia author. This document maps every brain-dump line to a concrete edit, marks status, and lists the open decisions that need the author's call before the mass edit is applied.

Status legend: READY = unambiguous, can implement now  |  NEW = new unit/item/commander to author (defaults proposed)  |  DECIDE = needs the author's input.
Mod mechanics established: DE keeps EA Pelagia's vanilla roster and modifies units in place via #selectmonster <id>. Each Pelagia unit exists as two IDs — an underwater base and a swimming/floating twin (DE adds #float so the whole roster can fight on land, which is Pelagia's "Closed Realm" gimmick). Stat/cost/gear edits must be applied to both forms. Armour/weapons are referenced by numeric ID. There is no per-unit recruit-removal command in Dom6 — removing a unit and adding new recruits both require #clearrec + an explicit rebuilt roster in the nation block (see Decision 1).
